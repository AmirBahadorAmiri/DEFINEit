# دیفاینیت (DEFINEit) 🌐
### متن را ترجمه کنید، واژه بگردید و به چند زبان گفتگو کنید

**دیفاینیت** اپلیکیشن اندرویدی ویژهٔ کاربران فارسی‌زبان است که مترجم گوگل، دیکشنری آفلاین انگلیسی–فارسی و حالت گفتگوی چت مانند را در کنار هم قرار می‌دهد.

## 🆕 تغییرات نسخهٔ ۲.۰.۰ — گفتگوی هوشمندتر

تمرکز این نسخه بهبود جریان گفتگو و سامانهٔ مشخص نسخه‌ها است:

*   **حالت Thinking:** پیام پاسخ بلافاصله با وضعیت `Thinking...` نمایش داده می‌شود تا درخواست تمام شود.
*   **پاسخ ماشین‌تحریر:** متن ترجمه‌شده حرف به حرف چاپ می‌شود و سرعت آن با طول پاسخ تنظیم می‌گردد.
*   **تلاش مجدد در خطا:** با لمس پاسخ ناموفق، منوی پاپ آپ TelegramDialog باز می‌شود و همان متن و زبان‌ها دوباره ارسال می‌شوند.
*   **نسخه‌بندی شفاف:** `versionCode` و `versionName` از `versionMajor`، `versionMinor` و `versionPatch` در `app/build.gradle` ساخته می‌شوند.

## 🌟 ویژگی‌های کلیدی

### 🌍 مترجم
*   ترجمه بر پایهٔ گوگل ترنسلیت با پشتیبانی از زبان‌های گوناگون مبدأ و مقصد.
*   ترجمهٔ خودکار پس از مکث کوتاه هنگام تایپ و جابه جایی زبان‌ها با یک لمس.
*   کپی نتیجه، پخش صوتی با Text-to-Speech و ورودی صوتی برای متن مبدأ.
*   صفحهٔ جداگانهٔ انتخاب زبان و بررسی سطح صدای دستگاه پیش از پخش.

### 📚 دیکشنری فارسی
*   جستجوی آفلاین واژه‌های انگلیسی ↔ فارسی با دیتابیس محلی Room.
*   جستجوی زنده به هر دو زبان پس از مکث کوتاه هنگام تایپ.
*   جستجوی صوتی و منوی پاپ آپ برای کپی، تلفظ یا اشتراکگذاری واژه.

### 💬 گفتگو (Conversation)
*   ترجمهٔ دوطرفه به سبک چت برای مکالمه‌های واقعی.
*   یک دکمهٔ ارسال و یک دکمهٔ میکروفون برای جفت زبان انتخاب‌شده.
*   **پاسخ به سبک دستیار هوشمند:** جایگاه `Thinking...` به جواب تبدیل می‌شود و با افکت ماشین‌تحریر چاپ می‌گردد.
*   **منوی تلاش مجدد:** ترجمهٔ ناموفق در چت می‌ماند و با لمس پیام دوباره ارسال می‌شود.

## 🛠 تکنولوژی‌های استفاده شده

در توسعهٔ دیفاینیت از ابزارها و کتابخانه‌های زیر استفاده شده است:

*   **زبان:** Java 11
*   **معماری:** Activity و Fragment همراه با دیتابیس محلی Room
*   **دیتابیس:** Room 2.8.4 (دیکشنری آفلاین)
*   **ارتباط با شبکه:** OkHttp 5.4.0 (درخواست‌های گوگل ترنسلیت)
*   **رابط کاربری:** AppCompat، Material Components، ConstraintLayout، chip-navigation-bar
*   **همگامی:** RxJava3 و RxAndroid (ایجاد تاخیر در جستجو و ترجمه)
*   **صوت:** `RecognizerIntent` اندروید و پوشش Text-to-Speech به نام `TTsSingle`
*   **سایر موارد:** منوهای TelegramDialog، Logger و QShare

## 🚀 راهنمای نصب و اجرا

۱. ابتدا پروژه را از GitHub کلون کنید:

```bash
git clone https://github.com/AmirBahadorAmiri/DEFINEit.git
cd DEFINEit
```

۲. پروژه را در نسخهٔ بهروز **Android Studio** با SDK شمارهٔ ۳۷ باز کنید.

۳. صبر کنید تا Gradle سینک شود و وابستگی‌ها دانلود شوند.

۴. اپلیکیشن را روی گوشی یا شبیهساز با **اندروید ۸ به بالا (API 26)+** اجرا کنید:

```bash
./gradlew assembleDebug
```
